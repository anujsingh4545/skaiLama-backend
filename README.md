# Technical Notes
- Build using standard React + Express + Mongodb + Tailwind + redux + redux thunk + Zod validation.
- For auth used jwt + cookies, which holds an expiry date of 7 days.
- Used aggregation pipelines to optimize query.
- Used best principles to write code.
